Einmalige Einrichtung
Für die Kollaboration wird eine kostenlose Firebase-Datenbank benötigt.
Einmalig einrichten — dauert ca. 5 Minuten.
1Gehe zu console.firebase.google.com und klicke auf „Projekt erstellen" (kostenloses Konto reicht).
2Im linken Menü: Erstellen → Realtime Database → Datenbank erstellen. Standort egal, Modus: „Im Testmodus starten".
3Nach dem Erstellen siehst du oben eine URL, z.B. https://mein-projekt-default-rtdb.europe-west1.firebasedatabase.app
4Kopiere diese URL und füge sie unten ein. Fertig — die Schüler-URL ist dann einfach diese HTML-Datei.
Bitte eine gültige Firebase-URL eingeben (beginnt mit https://).
Die URL wird lokal in diesem Browser gespeichert.
Schüler sehen diesen Screen nicht — nur beim ersten Öffnen auf dem Lehrergerät.
